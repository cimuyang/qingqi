# 轻启

![](https://github.com/cimuyang/qingqi/blob/main/%E8%BD%BB%E5%90%AF-%E5%AE%A3%E4%BC%A0%E4%BB%8B%E7%BB%8D-16x9.png)

## 功能

- 自定义分组名称、颜色和启动顺序，支持复制、排序和拖入添加。
- 支持 EXE、桌面快捷方式、文件、文件夹与 HTTP / HTTPS 网页，可设置启动参数和工作目录。
- 分组每页显示 4 项，搜索可定位到应用所在页；启动分组始终打开全组应用。
- 支持单项启动、启动全部、启动间隔和分组桌面快捷方式。
- 显示启动进度，部分失败后可仅重试失败项。
- 支持启动完成后自动退出、登录 Windows 时打开启动器、配置导入与导出。
- 后台加载图标、后台原子保存、短动画、窗口位置恢复与已有实例唤起。
- 快捷方式图标多层回退、失败自动重试，右键应用可“刷新图标”；不提供自定义图标设置。

## 使用

Windows 10 / 11，需 .NET Framework 4.8 或兼容更新版本。双击根目录的 `轻启.exe` 即可运行，也可单独复制到其他文件夹。

- 新建分组，拖入快捷方式或添加应用、文件、文件夹及网页。
- 点击“启动分组”开启全组；每页显示 4 项，支持搜索、排序、复制和桌面分组快捷方式。
- 删除分组、移除应用需在原菜单项再次确认；按 `Esc` 或点击外部取消。仅删除启动配置，原软件与文件保留。
- 设置支持启动间隔、启动完成后退出、登录 Windows 时打开轻启，以及配置导入导出。

开机启动需勾选后点击“保存设置”，只打开轻启。程序移动后，保持勾选并保存可更新路径；若 Windows 已禁用启动项，请通过设置中的入口在系统中启用。

## 数据

配置保存在 `%LOCALAPPDATA%\OrbitLauncher`，不随程序上传。保存保留上一版备份；重要配置可自行导出。

## 构建与验证

使用 C# / WPF / .NET Framework，无第三方依赖。构建使用 Windows 自带编译器：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1
```

源码位于 `src/`，测试探针位于 `tests/`。验证使用独立数据目录，自启动测试使用临时注册表分支并清理，不修改实际启动项。`qa/` 中的验证产物含本机路径，不应上传。
